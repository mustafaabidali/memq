# Security

Report a security bug through **Security → Advisories → Report a vulnerability**
on GitHub, when that option is available.
If it is missing, open an issue asking for a private way to report the bug.
Keep the bug details out of that public issue.

In the private report, include your memq version, operating system, steps to
repeat the bug with made-up data, and what went wrong.
Leave out passwords and private chats.

Fixes go into the current development branch. Older versions may need an upgrade.
